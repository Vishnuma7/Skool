# Find Your First AI Agent
**Free activity from the Agentic SCM community** | **Time:** about 15 minutes | **You'll need:** your completed ERP Time Drain Calculator

> Think of an AI agent as a smart new intern. It can read, think, use tools and act, but it needs a clear job description and a manager who signs off on important things. Today, you write that job description.

## Worked example: Sarah at BrightLeaf Supplies

| Step | Sarah's answer |
|---|---|
| Time drain | Checking stock in Odoo against reorder points every morning and emailing suppliers (about 4 hours a week) |
| Door(s) needed | ERP (stock levels and suppliers in Odoo) + database (a Google Sheet to log every order) |
| Job description | **When** it's 8:00 every weekday morning, **my agent will check** Odoo stock against each product's reorder point **and then** draft a purchase order for anything running low, **and ask me before** sending any order to a supplier. |

## Step 2: Which "door" does each one need?

Every agent reaches data through one (or more) of 3 doors:
- **ERP** = the company's central filing cabinet and rulebook (stock, orders, suppliers, customers)
- **API** = a waiter in a restaurant: you order, it brings back exactly what you asked for from an outside service (weather, exchange rates, holidays, carrier tracking)
- **Database** = a super-organised Excel workbook where the agent keeps its notes and logs

> PRO TIP: Not sure? If the data lives in your company's main system, it's the ERP door. If it comes from outside your company, it's the API door. If it's a list you keep yourself, it's the database door.

## Step 3: Write your agent's job description

Pick your #1 time drain and fill in the template. Keep it to one sentence.

> **When** ______________________ happens, **my agent will check** ______________________ **and then** ______________________, **and ask me before** ______________________.

Your agent's name (optional, but fun): ______________________

My sentence:

______________________________________________________________________________

______________________________________________________________________________

> BEGINNER MISTAKE: Leaving out the "ask me before" part. A good agent always has a manager's signature before anything important happens, like sending an order or emailing a customer.
